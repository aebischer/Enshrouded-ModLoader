Enshrouded ModLoader SDK — ABI 1

Normative reference: STANDARD_V1.txt.
End-to-end tutorial: CREER_UN_MOD.md (English content; filename retained for links).
Localization guide: LOCALISATION.txt.
Public C/C++ Windows x64 ABI: include/enshrouded_mod.h.
Minimal example: example/example_mod.cpp and example_mod.dll.mod.

From the loader repository root, run build.cmd followed by build-sdk.cmd.
The latter builds the example, package validator and integration tests. Outputs
stay under build; it does not install anything or replace the game loader.
It needs the MinHook objects generated by build.cmd.

To build the example alone, open a Visual Studio x64 Native Tools prompt:
  example\build.cmd C:\path\to\package
Distribute the output's Mods subdirectory. Object files and import libraries
are build artifacts, not files to install as mods.

Validate from the loader repository root:
  build\validate_mod_package.exe build\sdk-package example/example_mod.dll

The SDK standardizes loader integration, not native gameplay mechanics.
It does not provide chest manipulation, rendering, placement or networking APIs.

Optional C++17 localization: include/enshrouded_i18n.h. Manifest text entries
require ModLoader 0.6.10 or later. The sample is bilingual English/French to
demonstrate translation and fallback; it is not a complete 15-language mod.
For full coverage, use tools/compile-translations.ps1 and tests/catalog_checks.h.
The current loader, CarryOn and Lantern catalogues cover all 15 game languages.
