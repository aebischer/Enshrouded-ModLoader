1. Close Enshrouded and back up your saves.
2. Extract the ENTIRE release ZIP into a folder. Keep Install.cmd, install.ps1
   and dist/dinput8.dll together. Do not run the installer inside the ZIP viewer.
3. Run Install.cmd. It detects Steam's game directory or asks for the folder
   containing enshrouded.exe. Wait for the installation/verification message.
4. Install compatible mods separately under Mods/EnshroudedModLoader in the game directory.
5. Start Enshrouded, open Edit -> MODS for the chosen world, enable the mods
   and configure them before starting that world.

Custom directory, from PowerShell in the extracted folder:
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -GamePath "D:\SteamLibrary\steamapps\common\Enshrouded"

Shared layout (the root proxy belongs to ModLoader standalone, or to Kiln):
Enshrouded/
  enshrouded.exe
  dinput8.dll
  Mods/EnshroudedModLoader/      separately installed mods
  ModLoader/mod-loader.log      diagnostics
  ModLoader/worlds/             per-world activation/settings
  RandomWorld/                  installer receipts/recovery (historical name)

The loader package does not include gameplay mods or test fixtures.

UPDATE: close the game, extract the new package and run Install.cmd. Profiles
are preserved. An unrelated dinput8.dll is not overwritten. If another loader
is detected, do not force replacement. Only one proxy can occupy this path.

UNINSTALL: close the game and run Uninstall.cmd. Profiles, logs and mod files
remain. Check a mod's removal requirements before loading a save without it.

COMPATIBILITY: Windows x64 client, enshrouded.exe SHA-256:
5D9EF2F140B8ED49E30DBEE655841B89D08BAEC20F799A1817E171A18A850C77
The installer refuses other executables. Dedicated servers and multiplayer
are not certified. Changed mods/settings may require a complete restart;
DLLs are not hot-unloaded.

The in-game interface supports all 15 game languages. This documentation and
the installer use English. SHA256SUMS.txt in release packages lists file hashes
for verification with Get-FileHash.

Source, documentation and public downloads:
https://github.com/aebischer/Enshrouded-ModLoader
No GitHub account is required to view the source or download releases.

PACKAGE DIRECTORY (0.6.12)
Mods/EnshroudedModLoader/<package>/<mod>.dll and <mod>.dll.mod.
Run Install.cmd before copying updated mod packages. It migrates recognized old
package folders from Mods, including resources and saved package data. Relative
mod IDs, enabled choices and ModLoader/worlds settings remain unchanged.
Mixed folders, linked paths and destination collisions are refused. Separate
mixed packages manually without renaming their relative IDs, then retry.
Failed installation restores the old proxy and package locations. If interrupted,
run Install.cmd again for recovery before starting the game.
Failure dialogs cover all 15 game languages, with English before the game locale
is available. Technical logs and installation instructions remain in English.

AUTOMATIC KILN DETECTION
Install.cmd uses the same compiled DLL in either mode:
- Without Kiln: <game>/dinput8.dll.
- With Kiln: <game>/kiln/native/enshrouded-modloader/modloader.dll and native.json.
It identifies Kiln by its PE export, without executing it, and preserves its proxy.
An owned old chain copy is removed together with its chain entries; unknown DLLs
are never removed. Keep RandomWorld receipts for automatic migration/recovery.
Enable this native module in your Kiln profile (or allow native drop-ins).
Kiln's disabled/no-mods policy is respected; our DLL does not bypass it.
Uninstall.cmd removes our managed files, not Kiln, world settings or mod packages.
If Kiln is removed, rerun Install.cmd to restore standalone startup.
See docs/kiln-bootstrap.md for current runtime compatibility limits.

TESTED KILN SETUP
Install Kiln first, then run this Install.cmd. Copy CarryOn/Lantern only into
Mods/EnshroudedModLoader, never into kiln/native or kiln/chain. Enable each mod
in Edit world -> MODS. Kiln is optional; the same downloads work standalone.
Solo validation: Kiln 0.2.0-dev.29.19-beta.1, ModLoader 0.6.14, CarryOn
0.1.52-dev, Lantern 0.1.31-dev. Lantern light and equipped restoration were
confirmed in game. Other frameworks and multiplayer remain uncertified.
